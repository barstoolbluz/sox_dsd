## Evidence added by the focused follow-up

`full-path.json` qualifies the actual P112 mastering FIR plus the final
production SRC at DSD256/512/1024, with default, 176.4 kHz and 192 kHz
outputs. It includes P07 finite composite comparisons, P17 high-rate native
front-end oracle samples, read-only encoder handoff measurements before SDM-8,
source-bound SRC coefficient/clock captures, 266 sampled SRC transfer/alias
measurements and nine actual file roundtrips. The source stage snapshots and
binding receipts reside in the delivery's `evidence/P112-src-snapshots/`.

The SRC sweep includes all four changed intermediate/output rate pairs. Its
worst sampled stopband uses the larger of the coherent folded-tone projection
and the total output RMS-equivalent gain, preventing an isolated weak Fourier
projection from concealing another alias. The numerical comparisons use the
existing 0.0001 dB passband, -160 dB rejection and P07 2e-9 interior
comparator. This is **sampled evidence**; the existing production FIR
qualifier separately measures its full stopband. Neither is a formal
interval bound for the final resampler or a proof about arbitrary SDM-8 noise.

The owner's private `peak0` track corpus, long soaks and independent commercial
media for P21 remain outside this delivery's test environment and have **not**
