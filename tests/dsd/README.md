# DSD tests and independent references

This directory holds runnable DSD regression tests, synthetic fixtures,
independent parsers, numerical references, benchmark drivers and the minimal
release-evidence fixture consumed by the 1.1.1 checks. It is not a repository
of historical qualification receipts. For the current user guide and release
behavior see [`docs/dsd/`](../../docs/dsd/README.md).

## Build and check

In a configured source checkout:

```sh
make check                        # generic SoX tests
make check-dsd                    # DSD phase runner (default: P18)
make check-dsd DSD_PHASE=P15
make check-dsd DSD_PHASE=P10
make check-dsd-cli
make check-dsd-release-111
make check-dsd-optimization
make check-sdm-guard-policy
make check-dsd-loud-encode
make check-dsd-loud-guard
```

Python numerical checks require `numpy`, `scipy` and `mpmath`. On systems
without a required CPU ISA, executable tier checks report `SKIP` rather than
pretending to qualify that ISA. Use `nix build .#checked` when Nix is
available to build and run the checked variant.

New test and benchmark runs write to `.dsd-check-results/` or a caller-chosen
`DSD_RESULTS` / `--results` directory, not to tracked history. For example:

```sh
make check-dsd DSD_PHASE=P10 DSD_RESULTS=/tmp/sox-dsd-P10
python3 tests/dsd/run.py --phase P10 --sox src/sox \
  --results /tmp/sox-dsd-run-P10
python3 tests/dsd/test_plan.py --sox src/sox \
  --results /tmp/sox-dsd-plan
python3 tests/dsd/review_111_evidence.py --check-expected
python3 -m pytest -q -p no:cacheprovider tests/dsd/test_reader_gate.py
```

## Input and output boundaries

- `fixtures/`: small committed DSF, DSDIFF, WSD, DoP and PCM stimuli,
  documented by `fixtures/manifest.json`; not generated by the implementation
  under test.
- `reference/`: independent reference parsers, vectors, metrology, and the
  P07 public-rate golden manifest originally recorded in the historical run
  directory. The historical copy remains in the evidence archive. The frozen
  P10 numerical qualification snapshot and certificate inputs are also
  retained here because the P10 phase tests consume them. Their byte-identical
  historical copies remain in the evidence archive.
- `release_evidence/`: a path-redacted 800-row release receipt and the empty
  soak-launcher fixture needed by the deterministic 1.1.1 evidence review.
- `ntf_study/` and `ntf_dsd1024/`: optional numerical research and replay
  scripts. Their recorded campaigns and provenance outputs reside in the
  separately published evidence archive. Some standalone historical replay
  scripts require restoring those archived inputs first.
- New `results/` directories are outputs and should not be committed. Old
  phase run receipts are available as a separate GitHub release asset named
  `SoX_DSD_1.1.1_Evidence_2026-11-09.tar.zst`.

`test_111_receipt_redaction.py` uses the shipped redacted fixture if its
pre-cleanup source is absent. The full receipt sanitizer can be run against
an authorized private source copy with `--source`; the pre-cleanup original
is not checked in after the history rewrite.

## Interpretation

An independent reference passing its named test is not equivalent to full
real-media, external software or physical transport qualification. The
synthetic-only `p21_independent_reader.py` campaign can deliberately exit 1
with `INCOMPLETE` when operator-supplied commercial media are absent, even if
all performed synthetic cases pass. Historical benchmark records are
reproducibility evidence, not automatically portable speed claims.

For controlled host benchmarking, use the documented repetition, warmup,
CPU and storage setup in [BENCHMARKING.md](BENCHMARKING.md).
