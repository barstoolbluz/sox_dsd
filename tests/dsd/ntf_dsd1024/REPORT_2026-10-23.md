## Design space and method

The control is `encode.mastering.v2.dsd1024`, exact source CLANS-7 at
45,158,400 Hz. Rebound the ten historical frozen filter families from
`src/sdm.c` (CLANS-4/5/6/7/8, SDM-4/5/6/7/8) without rewriting any
coefficients. Added the independent DSD512 designed order-7 `o7-r8-a20`,
`o7-r5-a20`, and `order7-pareto-g3p0` seeds. Swept resonator scaling around
sixth/seventh/eighth-order banks, using exact IEEE-754 hex coefficient
round trips for determinism. **55 distinct profiles in total**. Every
candidate retained its original order; no spectral interpolation was
substituted for the actual recurrence.

P19/P10 **native scalar** renderer (private scratch only), at native
45.1584 MHz, read deterministic binary64 at 176.4 kHz through the
existing mastering reconstruction path. Screening happens before any
fidelity ranking: a failed process, incomplete committed frames,
nonfinite state, overload, 28-bit excursions or degenerate run distribution
is excluded. Spectral residuals are measured after seven validated 2:1
reconstruction stages to 352.8 kHz and a fitted 997-Hz source tone/DC
removal (rather than measuring the source tone as shaped noise). The
primary 1.6-second tone has 0.4–1.2-second analysis. A second 601-tap
Kaiser FIR offers a reconstruction-sensitivity crosscheck.

The source 61-tap prefilter is already roughly -209 dB by 80 kHz, so
40–100-kHz results increasingly reflect the **noise floor**, and
100–150 kHz is a diagnostic noise-only band, not encoded audio fidelity.
Primary selection rule in the evidence: all four short native screens pass,
low 0–40 kHz does not worsen by more than 1 dB, and each of 40–100 kHz and
100–150 kHz improves at least 3 dB. The rule is a **research shortlist
heuristic**, not a qualification or proven psychoacoustic objective.

## Primary native spectral results

All dB figures below are windowed integrated **sine-equivalent residual
levels in dBFS**, measured from the same 176.4-kHz binary64 stimulus;
smaller/more negative is better, within this one test configuration.

| Experimental source bank | 0–40 kHz | 40–100 kHz | 100–150 kHz |
|---|---:|---:|---:|
| CLANS-7 incumbent | -203.53 | -182.03 | -143.72 |
| Historical CLANS-8 | -237.53 | -212.73 | -168.88 |
| Historical SDM-8 | **-243.92** | **-226.21** | -181.71 |
| SDM-8, resonators ×2 | -229.65 | -226.01 | **-193.34** |
| DSD512 transferred order7 r8 | -209.98 | -194.85 | -177.29 |
| DSD512 order7 `g3p0` | -202.94 | -201.17 | -200.39 |

Versus CLANS-7, the historical SDM-8 gains approximately 40.38 dB below
40 kHz, 44.19 dB in 40–100 kHz, and 37.98 dB in 100–150 kHz. The ×2
resonator variation trades some low-band floor for another 11.63 dB of
improvement in 100–150 kHz. The original DSD512 `o7-r8-a20` is useful
but not the best DSD1024 result: a design optimized for a different
sample clock should not control DSD1024 selection.

The original CLANS-4/5/6 and CLANS-8 and SDM-8 were **not excluded** from
this search. Original SDM-8 behaved much better than the historically
troubled DSD512-v1 eighth-order path in these DSD1024 runs; that is an
observation only at this clock and screen duration, not an inference that
DSD512-v1 is repaired or that all SDM-8 applications are stable.

## Nonlinear native results

- **220/220** native short screens: 55 candidates × high-peak 997-Hz tone,
  seeded bounded noise, positive/negative DC step, silence. All returned
  zero nonfinite states, zero overloads, and nondegenerate bit populations.
- **55/55** 1.6-second primary render/spectral results (separate native
  runs after screening). **23** satisfied the declared improvement rule.
- Shortlisted **five** designs—CLANS-7, CLANS-8, SDM-8, SDM-8 ×2,
  DSD512 order-7 `g3p0`—completed **32 uninterrupted seconds each**,
  1,445,068,800 native frames per design. Each reported zero nonfinite,
  overload, and 28-bit excursions; min28=7 for all, max28=21 or 22.
  This is not the official uninterrupted **3,600-second** qualification.
- 20 additional finalist native renders across quiet-997, 20-kHz tone,
  40-kHz tone and stress32; reconstructed spectra for all five on 20-
  and 40-kHz sources. The eighth-order advantages persist on those tones;
  we do not project them to arbitrary musical programmes.
- Independent alternative FIR for four primary spectra: maximum change
  of **0.01788 dB** over the three decision bands. This tests one
  sensitivity axis, not arbitrary hardware decoders.
- A deliberately deleted six-megabyte packed output was regenerated from
  frozen input, exact experimental executable, and receipt; SHA-256 and
  `cmp` matched byte for byte. No previous receipt was rewritten.

The **candidate-specific** nonlinear ceiling, protected-guard calibration,
longer-term metastability, and rare counterexamples remain unproven. A
linearized NTF peak or pole location is not accepted as safety evidence.

## Decision and next qualification gates

**Independent DSD1024 selection:** Do not mirror DSD512 `o7-r8-a20`.
Advance **historical SDM-8 and SDM-8 with 2× resonators** as primary
DSD1024 investigation choices, while retaining CLANS-8 as independent
family comparison and CLANS-7 as the frozen original control. The
transferred DSD512 order7 `g3p0` retains a notably lower 100–150-kHz
floor and is a useful counterexample/spectral Pareto point, but has a
0–40-kHz penalty versus the incumbent by this measurement.

**Self-generated DSD1024 read media:** Not admissible as independent
read qualification. Such files permit useful codec smoke/roundtrip testing
and writer-development tests, but independent external DSD1024 media or
separately qualified upstream DSD1024 reference is needed before a read
qualification decision. Write experimentation does not imply read approval.

**When CLANS-7 is the winner:** if challengers fail an uninterrupted
3,600-second candidate-specific nominal run, frozen worst-state guard
calibration and independent 36-case holdouts, adversarial stress, false
read qualification checks, native performance ceilings, bounded latency,
correct identity preservation across vector kernels/ISAs, spectral
reproduction on independent programme material, or quality acceptance.
CLANS-7 also wins if further statistically robust evidence makes the
measured spectral advantage irrelevant or harmful for the intended output
band. Until gates are complete, it remains the **only incumbent**, not
"inferior yet already promoted".

**Next implementation authority is not granted.** Candidate-specific P19
port/adaptation (without corrupting original P19), candidate-specific
frozen bounds and holdout suites, repeat native long soaks on a prepared
host, cross-ISA and performance benchmarks, and independent audio
qualification must all precede any production change. Maintain the
`CONTINUUM_EXTREMA_WAIVER_2026-10-21.md` without weakening its scope.
