**Outcomes wanted:**

Situational notes, possibly wrong or incomplete — trust the tree over them:

  written: clipping interpolation before the SDM and calling it stable,

  declining to claim; this phase has to avoid them while actually claiming
  something.
- P09's registry binds each profile to the original literal coefficient tables
