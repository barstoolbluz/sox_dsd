## Surplus, if you have room

Two items carried from earlier rounds. Both are optional; neither should
displace the work above, and each should be a separate, self-contained change.

**A missing Python module should not kill the gate.** `make check-dsd` currently
dies with a bare `ModuleNotFoundError` traceback on any host without `mpmath`
or `numpy`: `tests/dsd/test_decode.py` and `tests/dsd/certify_filters.py`
import both at module scope, and `tests/dsd/generate_coeffs.py` imports
`mpmath`, none of them guarded. The project's standard, which P00's harness
follows, is that a missing tool is a named unrun gate rather than a crash — and
P06's handoff mentions `mpmath` only in passing and `numpy` not at all. We
obtained P06's numbers by supplying both on `PYTHONPATH`, so this is a
reporting and declaration problem rather than a numerical one. Whatever shape
you choose, the numerical gates must still be impossible to pass silently
while unrun.

**`src/dsdiff.c` mixes tabs and spaces.** 89 code lines use spaces where the
file indents with tabs: 58 from the P02 read hotfix at four-space width, 21
from P03 at two-space (`dff_seek`), the rest scattered through
`dff_read_prop`, `dff_writeheader` and `dff_write_bits`. Make the file
internally consistent, as a whitespace-only change that `diff -uw` shows to be
empty. Note that some of those lines are continuation *alignment* rather than
indentation, including the top-level signature continuations in
`dff_write_bits` and `dff_read_fragment`, which the file keeps in spaces
deliberately. P06 declined this one, which was reasonable.
