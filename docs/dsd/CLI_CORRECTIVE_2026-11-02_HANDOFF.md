# SoX DSD CLI: post-R2 corrective handoff (2026-11-02)

## Provenance and scope

- Parent: `4e92201`, on branch `cli-legacy-route-corrective`.
- Authoritative reproduction package: `SoX_DSD_CLI_Checks_2026-11-02.tar.zst`.
- This corrective uses the existing command parser, DSD planner, `dsdpcm`
  effect, format handlers and numerical profiles. It changes no DSP algorithm,
  FIR coefficient, modulator, or DSD file-format implementation.

## Disposition of the reported observations

| Package observation | Resolution |
| --- | --- |
| `--decode conservative` and versioned v1 silently execute v2 at the implicit reconstruction boundary | Fixed: the inserted effect receives `conservative` for the frozen v1 profile. The implicit v2 path still uses its versioned canonical ID. An actual report and audio-byte comparison pin both decisions. |
| `dsdpcm -p mastering` now selects v2 rather than historical v1 | Intended CLI redesign behavior: `mastering` is the v2 default, `conservative` is v1. Do not rename v1 back to `mastering`. |
| `--dsd-mode legacy -m` rejects different native DSD bit clocks before planning | Fixed: common PCM reconstruction may reconcile native input clocks in auto or legacy mode. The planner still rejects unsupported and native-only operations. PCM-only mixing keeps SoX's rate check. |
| `rate -v dither -p 1` differs from historical implicit rate/dither output | Intended: `-v` changes resampling. No DSP change; document the distinction. |
| Full-scale synthetic sine fails DSD interpolation overload; `check-sync-url` fixture fails | Retain correct overload protection. Use `vol 0.5` to give the synthetic fixture headroom. Replace obsolete `--dsd-report` with `--report` in this test. |
| P15 default mastering test expects legacy mode to be rejected | Update assertion to require that explicit legacy mode runs the qualified graph and produces byte-identical PCM to automatic routing. |
| P15-R3 integration uses deleted flags and old `mastering` meaning | Migrate the tests to `--plan`, `--decode`, `--report`; require conservative v1 to differ from mastering v2, and reject unused decoder selectors in native-copy mode. |
| P18 default phase rewrites thirteen committed `plan-p08` receipts | Preserve those historical files. Default `DSD_RESULTS` now points to an ignored build-output directory, `.dsd-check-results/PHASE/`. Explicit `DSD_RESULTS=...` remains supported. |

## Reproduction

```sh
# From the Git bundle checkout on this branch:
autoreconf -fi
./configure
make -j4
make check-dsd-cli
make check-sync-url
make check-rename
OPENBLAS_NUM_THREADS=1 make check-dsd DSD_PHASE=P15
OPENBLAS_NUM_THREADS=1 make check-dsd
OPENBLAS_NUM_THREADS=1 make check-dsd-p15-r3
```

The phase results default to `.dsd-check-results/P15/` and
`.dsd-check-results/P18/` under the build tree. Override `DSD_RESULTS`
when the evidence must be retained outside the checkout. No historical
receipt should be modified by these invocations.

## Constraints and limitations

- The supplied host's `generate_coeffs.py --check` mismatch did not reproduce
  here: the P06 header and manifest regenerated byte-identically, and the
  standalone check passed. Cross-host source of that mismatch is unresolved.
  No numerical qualification data were rewritten or coefficients altered.
- A separate historical `DSD_PHASE=P02` run against the modern source fails
  its original expected-failure/fingerprint accounting: six former known
  failures now pass, and the P02 mutation-guard test expects those defects
  still to reproduce. The current P15/P18 gates pass. Do not weaken the
  P02 historical oracle to make a past-phase replay appear applicable.
- Hardware DoP playback, Windows/macOS builds, and unavailable optional
  codec configurations were not validated here.
- This corrective does not upgrade any experimental reconstruction profile's
  qualification status; the P15-R3 certification records remain authoritative.
