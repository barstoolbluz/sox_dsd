## Corrections and engineering boundaries

- `src/formats.c`, `src/sox_ng.h`: `sox_seek` normalizes an interleaved
  public sample offset down to a channel frame, rejects unsupported or
  known-length out-of-range targets before invoking the handler, and commits
  `olength` only after success. `sox_read` clamps a bounded request against
  a saturating known-length remainder, respecting both unknown-length
  conventions. There is no new per-sample hot-loop work.
- `src/dsf.c`, `src/dsdiff.c`: DSF and DFF/WSD interpret a normalized public
  sample offset as a *per-channel frame* before calculating block/byte/bit
  positions. Checked physical offsets reject overflows before movement;
  successful seeks invalidate private block/cluster cache positions. DSF
  accepts exact logical end without loading a nonexistent block. This resolves
  the DFF trailing-MANF case through core logical position; no redundant
  DFF remaining-audio counter was added.
- `src/wav.c`: save the read-side original total frame count and reset
  `numSamples` from that original count after a successful byte-exact seek.
  GSM WAV49 seeks now explicitly return unsupported without changing decoder
  or file position, as allowed by P03: the original block-rounded seek could
  report a false exact position because it did not restore predictive state.
  Packed non-GSM ADPCM continues to reject unsupported seeks.
- `src/formats_i.c`, `src/sox_i.h`, `src/raw.c`, `src/msupcm.c`, `src/prc.c`,
  `src/smp.c`: shared byte seeks use integer arithmetic with checked
  multiplication, base addition and representability in `off_t`, rather than
  double-based conversion and narrowing. MSU PCM accounts for two bytes per
  sample; SMP seeks reset its private remaining counter and no longer round
  up. Raw PCM and PRC pass the full public 64-bit offset.
- `src/flac.c`, `src/vorbis.c`, `src/opus.c`, `src/wavpack.c`: invalidate
  decoded leftovers/EOF on seek where needed and reject unrepresentable codec
  frame indices. FLAC's existing deferred seek continues to resolve before
  a subsequent read returns samples; failure is reported rather than
  returning buffered samples from an earlier position. Codec-specific
  execution remains unrun on this host (see limits below).
- `src/sox_ng.c`: interactive frame counts convert to checked interleaved
  offsets, with display/read counters updated only on success. Existing
  `optimize_trim` passes interleaved offsets already; it now derives the
  resulting counter from the core-committed position.
- `Makefile.am`, `test/Makefile.am`: retain the original `check-am` target;
  append the P03 direct seek probe to `EXTRA_PROGRAMS`, add the P03 phase to
  `check-dsd` and the new sources/docs to `EXTRA_DIST`.
- `tests/dsd/test_seek_contract.c`, `tests/dsd/test_seek.py`: independently
  construct fixture files, compare reads from numerous seek positions against
  the complete sequential decode, assert core positions, exact EOF, private
  rewind, out-of-range and overflow/no-movement behavior. Cover 1-6 channels,
  DSD non-byte boundaries, both DSF storage orders, DFF, WSD, WAV PCM,
  raw PCM, MSU PCM, independently constructed SMP and PRC, and GSM rejection.
  Three native WAV trim cases compare optimized output against both an
  independent PCM slice and the sequential effect-chain path.
- `docs/dsd/SEEK_CONTRACT.md`: complete seek-unit and handler inventory.
  `docs/dsd/handoffs/P03_CHECKPOINT.md`: continuation/recovery instructions.

No changes were made to filter/encoder logic, native DFF writing, the public
ABI, `SEEK_CUR`/`SEEK_END`, or unrelated playback behavior.

## Corrective addendum: zero-length DFF and Opus seek state (2026-10-08)

**Disposition: both identified defects corrected; all executable P03 gates pass.**
This addendum supersedes the earlier 50-case seek count for the corrected tree;
its original evidence and historical qualifications are retained unchanged.
The input for this correction is `sox_ng-P03-complete.tar.gz` (SHA-256
`99b38a9bcc5ad066d259d4b6310846f16fd3fa907b5f05bbd94ed18b410e696a`).

### Scope of production changes

- `src/dsdiff.c`: `dff_read()` returns zero immediately if the already parsed
  `dff->data_size == 0`, even if a following MANF chunk is physically present.
  Generic zero/unknown-length semantics and nonempty DFF handling are unchanged.
  No additional state or remaining-samples counter was added.
- `src/opus.c`: after successful `op_pcm_seek()` and its preexisting signed
  frame-bound check, reset `vb->start`, `vb->end` and `vb->eof`. Failed seeks
  return the original error with the application-level buffer and EOF intact.
  No decoder lifecycle, allocation, API or per-sample changes were introduced.

### Focused regression tests

- `tests/dsd/test_seek.py` uses the existing writer-independent DFF fixture
  generator to add empty DSD chunks with *and without* a correctly declared
  following MANF, in 1-, 2- and 6-channel layouts. Nonempty eight-frame
  MANF controls use the existing seek/sequential comparisons.
- `tests/dsd/test_seek_contract.c` adds a zero-audio oracle independent of
  the decoder under test. It checks a declared length of zero, **zero samples
  returned** and `olength == 0` before and after three successive
  `sox_seek(ft, 0, SOX_SEEK_SET)` operations. Using a sequential decode as
  the reference would reproduce the original bug on both sides.
- The existing optional-codec probe now includes a long stereo Opus fixture
  (12,345 input PCM frames, more than the Opus 4,096-byte decoded buffer),
  alternating seeks/rewinds, comparisons to an independent full sequential
  decode and verification of buffered samples after a rejected seek.
  Executable Opus coverage requires an Opus-enabled build and is **unrun** on
  this host; no pass is inferred from source inspection.
- A negative control linked the revised empty-DFF probe against the compiled,
  uncorrected P03 candidate. It returned exit 1 with
  `zero-audio DFF returned metadata as audio`, proving the new test rejects
  the inherited defect. Evidence: `corrective/negative-control/`.
