## Corrective implementation

The principal named inherited failure, `dsf_type5_channel_identity_loss`, is
resolved by retaining and writing **DSF Type 5** as distinct from Type 4,
regardless of their equal channel counts. DSD bit chronology stays unchanged.

- `src/sox_dsd.h`, `src/dsd_layout.c`, `src/dsd_layout_i.h`:
  New opaque, independently owned channel-layout snapshots; ABI-compatible
  additive C entry points; copy-out versioned prefix records; channel-role
  getters/setters; original DSF type, original four-byte DFF IDs, optional
  LSCO and uninterpreted WSD `ch_asn`; pure-map permutation/subset and
  mix-invalidation operations; exact WAV speaker-mask/order helper.
- `src/formats.c`: Add `sox_open_write_dsd()` without changing the existing
  writer API. Clone layout into handler-private state *before* `startwrite`;
  free it on all normal and error exits. Reject unsupported DSD type, channel
  counts and WAV encoding before opening or truncating the destination.
- `src/dsf.c`, `src/dsdiff.c`: Preserve original DSF Type 4/5, physical DSF
  bit packing, DFF CHNL IDs in physical sample order, optional LSCO whether it
  precedes or follows CHNL, and opaque WSD provenance. A contradictory known
  LSCO emits a diagnostic but cannot reorder or rename channels. A one-channel
  DFF `C   ` ID maps to mono without altering multichannel `C` semantics.
- `src/wav.c`: Read actual WAVE_FORMAT_EXTENSIBLE speaker masks and write
  exact output masks for uncompressed integer and floating-point samples.
  Preserve the Type 4 (`0x33`) / Type 5 (`0x0f`) difference; only name WAV
  roles supported by the source. Decode multichannel center (bit `0x4`) as
  `FC`, not `MONO`.
- `src/sox_ng.c`, `src/remix.c`, `src/dsd_layout_query.h`: Add
  `--dsd-layout role,...` and `--dsd-layout-loss error|warn` (default error);
  carry identities across proven pure `remix` maps; invalidate on mixes and
  unknown channel transforms; insert an explicit final permutation when WAV
  mask order differs from input order. Missing/unrepresentable identities are
  rejected before file creation or require the documented warning override;
  no false DSF type is permitted. Ordinary PCM-to-PCM semantics remain
  unchanged.
- `src/Makefile.am`, `test/Makefile.am`, `Makefile.am`, `sox_ng.1`:
  Include/export the public header and compilation unit, distribute the tests
  and fixtures, document CLI behavior, and add P04 to `make check-dsd` without
  generating a conflicting generic `check-am` recipe.
- `src/effects_i_dsp.c`: Suppress two preexisting GCC-ignored STDC pragma
  warnings only on compilers for which the pragmas have no effect. DSP
  execution, numerical constants, and conversions were not altered.
- `tests/dsd/reference/writer.py`: For P04 and later, the existing six-channel
  native chronology test now explicitly assigns BL/BR on ambiguous DFF-to-DSF
  input, instead of relying on a semantically false side/back guess. The old
  exact bit-equality and frame-count assertions remain unchanged. This is a
  documented test-oracle correction required by P04's channel identity rule,
  not a relaxation of numerical acceptance.

No changes to the legacy public `sox_ng.h` structure layouts, DSD hot-loop
sample conversion, filtering, gain, dithering or codec internals are part of
P04. There is no global layout pointer map or comment-tag transport.
