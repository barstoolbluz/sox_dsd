## Implementation

Only three production files change. The entire public ABI and the inherited
P01 write implementation are unchanged.

- `src/dsf.c`: retain byte, bit and channel-block position across calls;
  bound reads by logical sample count and full channel frames; accept empty
  logical streams without loading a block; normalize DSF bps=8 (MSB-first)
  exactly once when loading a block rather than in the per-bit path; validate
  physical/data chunk extents, block sizes, bit order and multiplicative
  counts. Retain the existing P03 seek implementation unchanged.
- `src/dsdiff.c`: decode one frame from an already loaded channel-byte
  cluster, loading a new cluster only after its eight bits are consumed.
  Both DFF and WSD use this reader. Read in full interleaved channel frames;
  accept one-byte mono audio and zero-size audio, and preserve logical length
  without a new remaining-audio counter. Parse `FRM8`, `PROP/SND` and child
  extents with explicit lengths; require initialized `FVER`, `FS`, `CHNL`
  and `CMPR` before audio, check physical skip results, and consume ignored
  metadata on forward-only streams. The DFF seek unit calculation remains
  owned by P03; successful seek invalidates the cached cluster.
- `src/dop.c`: prevent partial DoP words from consuming more input or
  producing samples when the destination cannot fit one full channel frame;
  retain pending words during insufficient-capacity drain calls.

Test/harness changes: `tests/dsd/test_io.c` (chronological FNV and read
observability), `tests/dsd/test_streaming.py` (new independent matrix),
`tests/dsd/test_dop_capacity.c` (new direct effect tests),
`tests/dsd/bench_read_p02.py` (new reader-specific performance samples),

and candidate large-buffer repetitions. See `bench-read/bench-read.json` and
