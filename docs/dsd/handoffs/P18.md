## Implementation (minimal production footprint)

- `src/dsd.c`, private `src/dsd.h`: explicit native-rate × container/endpoint × operation decisions. Each DSD512 and DSD1024 DSF read/write, general DSDIFF read/write, DoP transport and WSD read row is **DENIED_UNQUALIFIED**. The existing DSD64/128/256 production capability table and private P17 DSP candidate identities remain unchanged. Invalid format/rate/operation pairs fail distinctly. Checked uint32 clock conversion, native/16 transport arithmetic, and checked uint64 DSF/DFF physical extent helpers do not imply capability.
- `src/dsf.c`, `src/dsdiff.c`: reject high-rate input before payload allocation or decode; output handlers independently refuse high-rate writes before a format header. DSF input physical sizing now reuses checked count/blocks arithmetic. WSD high-rate native input also refuses explicitly. Existing writer rules, silence padding, channel identity and lower-rate output logic are preserved.
- `src/dop.c`, `src/dsd_plan.c`: direct DoP effect startup and CLI planning both enforce the closed gate. High-rate native output planning reports `DSF write` or `DSDIFF write` with native rate and P17-qualification reason, instead of selecting a lower rate or producing a file. The only valid same-channel DoP arithmetic is 22,579,200/16 = **1,411,200 Hz** and 45,158,400/16 = **2,822,400 Hz** PCM; neither transport is enabled.
- `test/Makefile.am`, root `Makefile.am`, `tests/dsd/run.py`, `tests/dsd/measure.py`, `tests/dsd/bench.py`: register P18 in the inherited real DSD unit, integration, numeric and benchmark runners. `Makefile.am` lists all 40 frozen reference vector files in `EXTRA_DIST` for complete source distributions. The phase remains explicit about **development-only** legacy benchmarks and **UNRUN** high-rate file/transport throughput.
- `tests/dsd/test_p16.py`: correct an inherited **one-line idempotency defect**: when all 219 records are already cached PASS, its previous loop performed no `save()` and the final summary accessed an unset `verdict`. An unconditional final `save()` restores a repeatable exit 0 with the same case evidence; no test acceptance condition was relaxed. The defect was exposed by a second `make check-dsd` replay (`build/check-dsd-final.exit=2`), which must not be mistaken for a runtime regression. Requalification runs fresh and fully cached are recorded separately.
- `tests/dsd/test_p18.c`: executable private registry, actual DoP-startup refusal and 64-bit overflow/duration/unit tests. `tests/dsd/test_p18.py`, `tests/dsd/reference/p18_fixture_matrix.json`, `tests/dsd/fixtures/p18/`: independently generated format records and frozen small reference byte vectors, checked without changing bytes on a normal run. Exercises 1/2/6-channel identities, block and external padding, partial bytes/markers, native low-rate round trips, packed input and high-rate CLI denial with no output file.
- `docs/dsd/P18_COMPATIBILITY_LEDGER.md`, `docs/dsd/P18_RELEASE_NOTES.md`, `docs/dsd/P18_RELEASE_MANIFEST.schema.json`, `docs/dsd/P18_RELEASE_MANIFEST.json`, `tests/dsd/seal_p18_manifest.py`, `README.md`, `docs/dsd/README.md`, `sox.1`: source-bound capability manifest, accurate end-user refusal notice and format/transport scope. ### Benchmarks and host limitations

The provided development environment was Linux x86_64, **AMD EPYC 9V74**, approximately 6 GB memory available to the container; this is **not** a dedicated repeatable performance host. The inherited benchmark uses a very short **0.006-second source duration**, one repetition, DSD64/128/256 only, 1/2/6 channels, and 352.8/705.6 kHz PCM outputs. It is a functional throughput smoke observation, **not** a calibrated high-rate performance or nonregression certificate. No per-sample processing path changes were made in P18; production additions occur at gate/preflight/start boundaries. The sampled P17 spectral and private DSP results remain `PASS_DEVELOPMENT_TESTS_UNQUALIFIED`.

### Deviations and future work

The SOW requests real DSD512/1024 file round trips, external software/player evidence, hardware only for claimed devices and high-rate end-to-end benchmark observations. Under the explicit P18 authorization **all such high-rate operations remain disabled**, so impossible or prohibited end-to-end tests are reported **UNRUN**, with synthetic format/DoP structure and observable refusals tested instead. WSD receives a defensive high-rate read refusal because it shares the native DSD reader path; it is not a new supported format.

P18 **does not** permit a P19 enablement or release based on these results. The next permitted activity is obtaining and independently qualifying P17 exact-rate DSP and source-program certificates, real reference media and platform interoperability, resolving P15 standing obligations, and seeking new explicit operator authorization before changing any specific capability row. No rate may silently inherit another rate's qualification.

## Corrective follow-up (2026-10-21)

The original P18 implementation was independently found to allow **default/legacy DSD512/1024 output requests to be down-rated to DSD256** by `set_output_format()` before the writer's P18 gate, and to mislabel uppercase DFF destinations as DSF in planner refusal diagnostics. Those defects were corrected without enablement. The fully replayed result is **398 C checks**, **106/106 P18 CLI cases**, **219/219 fresh and cached P16 cases**, **45/45 DSD regression cases**, generic `make check` PASS, numerical-development and inherited low-rate bench commands PASS, `check-rename` PASS, and source-bound manifest `P18_COMPLETE_FAIL_CLOSED` with all 12 rows disabled.

**The original 372-check/88-CLI figures above are historical, superseded by the corrective results.** Complete causes, files, test commands, current receipts, reproducibility and limitations are recorded in [`P18_CORRECTIVE_2026-10-21.md`](P18_CORRECTIVE_2026-10-21.md).
