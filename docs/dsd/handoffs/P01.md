## Changes

Only `src/dsdiff.c` changes production behavior. All **229** other original
production C/header files retain their recorded P00 hashes. Public headers,
CLI, generic regression sources, original fixture manifest and all previously
recorded evidence remain unchanged.

- Zero the first byte-cluster accumulator. Packing still preserves the existing
  chronological 0x69 tail-completion convention.
- Use checked physical spans, `12 + payload + (payload & 1)`, throughout header
  size calculations, including the enclosing FRM8 physical span. Count audio
  once. CMPR contains 14 text bytes, a 19-byte payload and one external zero pad.
- Account for every successfully written channel cluster in one place,
  including a silence-completed final cluster. Exclude external audio padding
  from sound length and include it in the parent size.
- Distinguish provisional unknown lengths from final known zero. Force the
  empty audio-size field to overwrite its old sentinel: the generic sparse
  zero-write optimization otherwise seeks over existing nonzero bytes.
- Return a short sample count when a cluster write fails, retain that failure
  until finalization, and avoid retrying it as a tail. Propagate tail/pad,
  rewind, header-update and buffered-flush failures. Free the accumulator on
  initial-header failure and every finalization path. These are writer/API
  status checks; P05 separately owns generic CLI final-close status handling.

measure.py,bench.py,test_io.c,README.md}`. New inputs: `tests/dsd/{test_dff_writer.c,
bench_dff.py,reference/writer.py,fixtures/p01_writer_vectors.json}`. This handoff,

The distribution manifest at `tests/dsd/results/P00/P00_SHA256SUMS.txt` is
