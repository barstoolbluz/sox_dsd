**State:** corrected v2 experimental code, frozen training/holdout evidence and a source-bound unqualified certificate. Do not change the seven-degree coefficient identity or retrain the frozen bounds to make a later failure pass. Do not enable public high-rate read/write/DoP capabilities.

```sh
tar --zstd -xf sox_dsd-dsd1024-v2-corrected-2026-10-21.tar.zst
cd sox_dsd
sha256sum -c P19_BUNDLE_SHA256SUMS.txt
python3 tests/dsd/generate_p17_qualification_certificates.py --check
python3 tests/dsd/test_p17_qualification_registry.py

python3 tests/dsd/p19_qualify_dsd1024.py verify
python3 tests/dsd/p19_qualify_dsd1024.py adjudicate
```

Rebuild the source from scratch using the normal SoX toolchain. Do not assume that archived test executables can run on another CPU or system. On this x86_64 Linux validation host:

```sh
autoreconf -fi

make -C test -j6 dsd_test_p10 dsd_test_p17 dsd_test_p17_dsf dsd_test_p18
```

`tests/dsd/results/P19_DSD1024_CORRECTION/executables/` carries two **recorded** P19 binaries: the unguarded training binary and the subsequently frozen-guard binary. Their SHA-256 values match their respective immutable receipt sets. New independent experiments should use freshly built binaries and new output paths. Stored receipts cannot be silently overwritten; existing split receipts are reused only when their recorded identities match. Archive digest records attest to bytes only, not to the trustworthiness of the test host.

## Required prepared-host sustained soaks

Run on the target hardware after recording CPU model, available ISA, compiler options, CPU governor, affinity, temperature/frequency and interference. Use **new** prefixes and retain the entire raw snapshot directory. Each mode uses **the corrected v2 modulator**; `original-v1` and `nominal-v2` name inherited *stimulus programs*, not modulator profiles.

```sh
mkdir -p /tmp/p19-host-soaks
for mode in original-v1 nominal-v2; do
  prefix="/tmp/p19-host-soaks/$mode"
  python3 tests/dsd/p19_soak_run.py \
    --rate 45158400 --seconds 3600 --segment-seconds 60 \
    --mode "$mode" --prefix "$prefix"
  python3 tests/dsd/p19_soak_assess.py \
    --rate 45158400 --seconds 3600 --require-sustained \
    --prefix "$prefix" --results "$prefix-assessment.json"
done
```

The assessor checks all required counter/status fields and binary/source/guard/runner SHA receipts, the committed frame count, no first-bad frame, the original 28-bit population gate, all eight frozen coordinate bounds and snapshot hashes. A missing execution receipt, changed binary/guard, short run or numeric failure **cannot pass** the sustained gate. Host facts not available in this environment remain the operator's responsibility. This input gate alone does not qualify media, reference-audio performance or file-writer interop.

## Further changes

Retain the v1 profile unchanged for comparison. If revising the v2 coefficients or guard code, do not replace this frozen evidence. Assign a **new profile version**, collect new unguarded training results, independently freeze new bounds, build a fresh guarded executable, and repeat the separate holdout and sustained tests. Reissue a new evidence binding. Record independent audio quality before any production consideration.
