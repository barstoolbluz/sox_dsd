# P06 handoff: certified filters and finite scalar reconstruction

## Scope and disposition

Implemented P06 against the supplied `sox_ng-P06-d8295118.tar.gz` source
(SHA-256 `cfe56558046ce8faa130faaaa41f5b5259d3eb3485009e5140d2cf16038e75f0`).
This is a source-only continuation, not a built binary. No `.git` was supplied.
P00-P05 behavior and the P05 opt-in planner remain intact. The P06 engine is
private: no automatic CLI DSD-to-PCM activation, arbitrary-ratio SRC, SIMD,
new encoder, or 512-rate enablement was added. Those belong to later packets.
The optional, unrelated `src/dsdiff.c` indentation cleanup was deliberately
omitted. Previously delivered P00-P05 evidence was not edited, apart from
regeneration of the specifically requested P00 file-hash inventory.

## Implementation and changed source

- `src/dsd_coeffs.h`: generated, checked-in C99 hexadecimal binary64 taps;
  four immutable banks (57-tap halfband, 117-tap mastering64/256,
  153-tap mastering128, 257-tap wideband). Symmetric, unity DC and exact
  structural halfband zeros.
- `src/dsd_kernels.h`, `src/dsd_kernels_scalar.c`: scalar reference symmetric
  pair summation in binary64; no clipping, gain or dithering.
- `src/dsd_decode.h`, `src/dsd_decode.c`: private, bounded, interleaved
  multi-channel streaming API with factor-two decimation phases, checked
  allocations, individually 64-byte-aligned stage/channel histories, a
  mirrored ring halo, and no file-sized buffers or block shifts.
- `src/dsd.h`, `src/dsd.c`: one frozen descriptor per six supported
  mastering/wideband native-rate combinations, shared with the existing
  planner. No change to the public ABI.
- `src/Makefile.am`, `test/Makefile.am`, `Makefile.am`: source, test, and
  P06 runner registration, preserving earlier phase targets.
- `tests/dsd/generate_coeffs.py`: mpmath high-precision Kaiser generation
  from the design, with reproducible `--check` mode.
- `tests/dsd/reference/p06_coefficients.json`: hashes of the actual binary64
  coefficient words. Checked against the compiled C hex declarations.
- `tests/dsd/certify_filters.py`: independent final-byte frequency-domain
  certification: derivative-root searches for the banks, adaptive composite
  extrema, all coherent alias images, 75-digit checks near extrema.
- `tests/dsd/test_decode.c`, `tests/dsd/test_decode_faults.c`,
  `tests/dsd/test_decode.py`: compiled unit, deterministic allocation-failure
  and ring-alignment tests, and a direct independent 75-digit/long-double
  finite-convolution oracle.
- `tests/dsd/bench_decode.py`: scalar four-bank kernel and 18-profile/channel
  frontend benchmarks; `tests/dsd/bench.py`, `tests/dsd/measure.py`: P06
  qualification entry points.

## Reconstruction contract

All six supported profiles implement `D=2^stages` and
`G=sum_j (((L_j-1)/2)*2^j)` in native input frames. Stage phase bits are
`(G>>j)&1`; the cascade discards `floor(G/D)` causal outputs. The centered
intermediate frame count is `ceil(N/D)`. Streaming accepts only native-bit
`+SOX_SAMPLE_MAX` and `-SOX_SAMPLE_MAX`; outside the finite input its values
are **numeric `+0.0`**, not either bit symbol or a DSD silence pattern.
`finish()` is resumable under limited output capacity and is idempotent after
`DONE`; zero output capacity does not consume input. The engine returns binary64
intermediate values without subsequent SRC. Ring wrap, phase, 0..33-frame
inputs, irregular chunks, and interleaved 1/2/5/6-channel operation were tested.

## Numerical acceptance (final binary64 coefficients)

Evidence: `tests/dsd/results/P06/numeric/filter-certificate.json` and
`tests/dsd/results/P06/scalar/oracle.json`. Four of four independent bank
certificates and six of six composite-profile certificates pass.

- Stage-bank worst-case stopband: approximately -188.006 dB or better,
  against the 185 dB stage attenuation requirement.
- Composite-profile worst stopband: approximately -187.410 dB, against -160 dB.
- Worst coherent alias-sum attenuation: approximately -182.442 dB, against
  -160 dB; every image is included in the sum, not only final-stage aliases.
- Worst passband deviation: approximately 7.181e-9 dB, against 1e-4 dB.
- Scalar oracle: **1,056 vectors, 58,408 compared samples** across all six
  profiles and 1/2/5/6 channels; **5,656** 75-digit boundary/interior checks.
  Maximum sample error relative to the design's specified bound: 0.00004461;
  every tested point passes the required tolerance.
- Compiled C unit: **93,640** assertions, all passing. Fault injection:
  **52** assertions, including all four allocation sites and 64-byte alignment.
- The certification finds dense-grid extrema and refines candidate maxima at
  high precision; this is independent numerical evidence, not a formal
  interval-arithmetic proof of a continuum-wide upper bound.

The design-time NPZ candidate is **not** a certificate. Independent generator
results differ from those bytes at 28/113/149/257 coefficient words for
halfband/master64_256/master128/wideband respectively (all absolute
coefficient deltas <=3.89e-16). Differences are disclosed in
`tests/dsd/results/P06/numeric/candidate-comparison.json`; the original
`docs/dsd/evidence/` files are unchanged. No candidate was substituted for
final accepted coefficients.

## Executed gates and evidence

Reproducible commands run from the source root with `CFLAGS='-O2 -g'`:

```sh
autoreconf -fi
./configure --disable-shared --without-libltdl CFLAGS='-O2 -g'
make -j2
make check
make check-dsd
python3 tests/dsd/run.py --phase P06 --results tests/dsd/results/P06
python3 tests/dsd/measure.py --phase P06 --results tests/dsd/results/P06/numeric
python3 tests/dsd/bench.py --phase P06 --results tests/dsd/results/P06/bench
python3 tests/dsd/generate_coeffs.py --check
```

All eight listed build/regression/metrology/benchmark gates exited 0 in the
working tree; coefficient regeneration (`--check`) also exited 0. An independent
freshly staged source-only replay passed autoreconf, configure, make,
`make check`, `make check-dsd`, the P06 runner, numerical metrology and the
coefficient check (all exit 0). The scalar/development benchmark was executed
in the working tree, not in the replay. Replay exit codes and raw logs are
under `tests/dsd/results/P06/replay/`. `make check` preserved the inherited
generic suite (no known new failures); `make check-dsd` includes the P02-P05
contracts and P06 compiled and Python oracles. The separate P06 runner
remained **36 pass / 0 fail / 0 skip / 0 xfail**; this is a regression floor,
not numerical acceptance. The P06 metrology entry point reported **7 pass,
0 fail**. The P06 development benchmark completed the existing 36 workloads
and the new 18 frontend and four FIR kernel configurations. Both compiled
unit suites also passed an independent AddressSanitizer +
UndefinedBehaviorSanitizer build/run. Exact transcripts, exit codes, JSON
outputs and sanitizer logs are under `tests/dsd/results/P06/`. The checked-in
binary64 coefficient bytes are the sole target of final verification.

### Performance gate: inconclusive, not waived

The controlled-host criterion is at most **5% median regression** on
unmodified processing paths **with measurement noise below 2%**. The provided
container host did not satisfy benchmark preparation; nine repeatability
runs on CPU 0 had **9.5% spread**, greater than the 2% admissibility limit.
Therefore this host cannot certify or reject the 5% comparative gate.
Development timing and allocations are recorded in
`tests/dsd/results/P06/bench/` but are not presented as controlled-host
certification. The new private P06 engine is not activated by the CLI, so it
does not add runtime work to existing CLI paths. A prepared, low-noise
controlled host must resolve the inherited-path performance qualification.

### Other qualification boundaries

The later P09 analysis-v1 coefficients, corpus-based audio fidelity, and
independent quality measurements remain unrun; they are **not P06 completion
criteria**. Forced-SIMD/ISA execution is inapplicable to the scalar-only P06
engine; optional-codec coverage depends on installed codecs and is not
claimed without evidence. This handoff is numerical P06 complete, with the
separate environment-dependent throughput condition explicitly unresolved.
