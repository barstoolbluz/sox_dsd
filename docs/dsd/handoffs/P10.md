## Implemented signal path

`src/pcmdsd.c` implements graph int32 normalization, binary64 source-to-R SRC, a centered non-decimating bandwidth FIR at R, binary64 interpolation to the native clock, one resolved reference scale, and the original exact-rate scalar `sdm-8` recurrence. No intermediate int32 quantization, limiter, automatic attenuation, reset, dither or alternate modulator is inserted.

Mastering64 uses P/S/R = 20,000/40,000/88,200 Hz and 61 FIR taps. Mastering128 uses 30,000/60,000/176,400 Hz and 77 taps. Mastering256 uses 40,000/80,000/176,400 Hz and 61 taps. The DSD64/256 bank shares the same normalized response, not an incorrectly reused 2R decimation bank. Measured stopband rejection is 185.957109584 dB for that bank and 187.575036625 dB for DSD128. Both satisfy the prescribed passband envelope. The generator reproduces checked-in hexadecimal binary64 coefficients; the extrema calculation is numerical evidence, not an interval proof.

Both private SRC stages retain the specified 180 dB, 95% zero-dB-bandwidth, 50% linear-phase configuration. Identity SRCs bypass processing. The profile reports the effective passband intersection for low-rate inputs. Original native duration is `round_half_up(N_source * native_Hz / source_Hz)`. An independently rounded working length cannot shorten or extend it. DSF retains the logical count; DFF and DoP apply their declared transport completion.

Ordinary and mixed-with-PCM graphs use scale 0.5. Preserve-reference DSD remodulation uses 1.0; SACD-reference remodulation uses 0.5 to invert the decoder's gain of two. Explicit reference overrides, unity and -3 dB transformations, generated PCM, and mixed DSD/PCM routing have executable checks.

The admitted SDM-domain magnitude is 0.5 plus two source-int32 LSBs mapped by the resolved scale. Overload and nonfinite input fail. Finite per-coordinate guards are calibrated from training, frozen before holdout, and checked before a state bank commits. A failing process call exposes zero output frames from that call and latches the failure. Diagnostics identify the native frame, channel, coordinate, observed value, peak and minimum attenuation implied by that observed peak. Already completed output blocks and nonseekable output cannot be rolled back; existing CLI cleanup rules apply.

`src/pcmdsd_guards.h` embeds the hash of `tests/dsd/reference/p10_profiles.json`. These are explicitly negative certificates generated from `results/P10/certificate-input.json`. They bind the original coefficient identities, FIR and SRC policy, training guards, recorded holdout cases and failed soaks. They do not confer activation. The generator only produces negative certificates; a positive release decision is not automated here.

The uninstalled `test/sox_p10_candidate` executable uses two explicit GNU linker wrappers to exercise the production planner, effects graph and composite implementation despite the release gate. There is no environment-variable or public experimental switch that activates the failed profile. The test wrapper is a qualification tool, not a substitute released encoder. Its GNU-linker dependency is limited to this test executable.
