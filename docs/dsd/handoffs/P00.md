## P00a deviation: Automake `check-am` collision (October 8, 2026)

**Scope:** P00 test-build registration only; no P01 or production repair. The
supplied `test/Makefile.am` declared `check_PROGRAMS = dsd_test_io` while also
providing a legacy `check-am` recipe for `samples`, `wav_size_state_test`, and
`check.sh -n`. Automake then generated another `check-am` *recipe* to build
`check_PROGRAMS`. GNU Make warned that it was overriding the generated recipe;
which command survived depended on makefile ordering. This was a genuine P00
harness defect, even though the legacy checks happened to run.

**Correction:** Register the probe with `EXTRA_PROGRAMS += dsd_test_io` instead
of `check_PROGRAMS`. The existing `EXTRA_PROGRAMS = wav_size_state_test` remains
intact. `make check-dsd` already builds the probe explicitly with
`$(MAKE) -C test dsd_test_io$(EXEEXT)`, so this keeps its configured sources and
`libsox_ng.la` link flags without adding a build to ordinary `make` or
`make check`. Automake still writes a prerequisite-only `check-am: all-am`,
but does **not** generate a competing recipe. The sole `check-am` recipe is the
existing one that executes `check.sh -n`. Choosing `EXTRA_PROGRAMS +=` instead
of `noinst_PROGRAMS` also avoids changing ordinary `make`'s build set.

**Independent before/after verification:** Extracted the supplied unmodified
tree and the corrected tree into separate scratch build directories. In each,
`autoreconf -fi`, `./configure --disable-shared --without-libltdl
CFLAGS='-O2 -g'`, `make -j2`, `make check`, and `make check-dsd` (with a separate
scratch `DSD_RESULTS` destination) all returned exit code **0**. Before the
correction, `make`, `make check`, and `make check-dsd` emitted the duplicate
`check-am` recipe warnings; after correction none did. In both builds,
`make check` compiled `wav_size_state_test` and `samples` and ran `check.sh -n`.

configured `dsd_test_io` and returned **17 PASS, 19 named XFAIL, 0 XPASS,
0 FAIL, 0 skips**, with all **36 case names and classifications identical**.
Existing known defects and their repair phases remain untouched.
