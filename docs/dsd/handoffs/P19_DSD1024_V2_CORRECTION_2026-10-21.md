# P19: DSD1024 numerical correction and qualification boundary

**Date:** October 21, 2026. **Basis:** the previously verified P17 working-set archive, SHA-256 `dfb336688c55ddde450a56a8fc9ed2d263014fb7dc6aeb738c8b85f365126148`. The supplied working set has no Git metadata; `sox_dsd/main` revision `2bda0491` is an input assertion, not a locally verified Git commit.

## Disposition

**PASS: the reproduced DSD1024 numerical failure is corrected in a new experimental candidate.** **NOT QUALIFIED FOR PRODUCTION.** The P17 eighth-order `encode.mastering.v1.dsd1024` remains intact, demonstrably unstable on sustained positive and negative DC, and blocked. The correction is a **separate** `encode.mastering.v2.dsd1024` seventh-order candidate. It uses the exact historical CLANS-7 binary64 coefficient words from the in-tree DSD256 SDM design, bound to the DSD1024 native clock; its qualification is independent of that historical use. No shared SDM recurrence, SIMD kernel, clipping policy, fallback, public high-rate capability or qualified low-rate coefficient is altered.

P17's frozen original high-rate bounds, its historical evidence and the accepted low-rate P10 certificate remain unchanged. The six P17 **unqualified** candidate certificates are source-rebound because `src/sdm.c` and `src/pcmdsd.c` now expose an additional private candidate; their qualification decisions are unchanged. The original P17 certificate registry and manifest are preserved in the P19 `preimage` evidence directory. P19 has its own seventh, **unqualified** source-and-evidence digest at `tests/dsd/reference/p19_dsd1024_v2_certificate.json`.

## Reproduced defect and correction

The inherited eighth-order recurrence entered numerical runaway on both polarities of DC after approximately 33.1 million native frames, reporting nonfinite state or the associated bound error; the deliberate overload was rejected by the state bound before the expected interpolation-envelope gate. Raising state ceilings would not resolve it.

The seventh-order candidate completed the complete P17/P10-derived DSD1024 experiment matrix at 45,158,400 frames/s. The new, independent **frozen** coordinate ceilings are `[32, 64, 512, 4096, 65536, 1048576, 67108864, 16]`, derived strictly as `2**ceil(log2(16*max(1,training_coordinate_max)))`. The last coordinate is inactive for the seventh-order recurrence; the conservative positive bound remains part of the eight-coordinate guard interface. No holdout result was used to tune the bounds.

## Independent checks reproduced in this working environment

- **Training:** 17/17 complete, no rejected input, including both 1.6-second DC polarities and 60-second sustained noise. Frozen provenance checks pass. Historical unguarded executable is retained with the receipts.
- **Holdout:** 36/36 correct dispositions, including 33 ordinary passes, two separately classified full-scale observations, and one deliberate overload rejected specifically at the interpolation-envelope gate. No nonfinite state or 28-bit population excursion. Guarded executable is retained with the receipts.
- **ISA:** 25/25 private *full-composite* tests: scalar, SSE2, AVX1, AVX2 and AVX-512, over five fixed test cases. This host supports these tiers. Full-bit identity between architectures is not required or claimed.
- **Reconstruction diagnostic:** independent SciPy FIR decimation of a 997-Hz, -6-dBFS test tone. Residual RMS equivalent: original eighth-order candidate **-202.45 dBFS**, corrected seventh-order **-198.77 dBFS** (about 3.67 dB higher). Both had zero measured PCM clipping in the analyzed window. This is one synthetic test, **not** independent audio-quality certification.
- **Independent clean-checkout replay:** after packaging the source, a separate extract passed `autoreconf -fi`, `./configure --disable-shared`, a fresh build, `make check`, the original P10/P17/P18 tests, 106 P18 CLI cases, 84 DSF fixtures, and four large streaming cases. The newly compiled scalar encoder then reproduced the exact frozen packed-output SHA-256 for both 1.6-second holdout DC tests: positive `2a5e8d65cb7804284da141edbd9d27816d5b54227d52da50f48cbc896278c9ff`, negative `68648048240448ad3b4691a210eb943350a5d71b38004f8eb1fffb608281824e`. Build and test logs in `regressions/` are from that clean replay.
- **Regression:** `make check`; P10 unit **105,482 assertions**; P17 unit **32,859 checks**, encoder **230 checks**, and matrix **8,640 pairs / 406,080 checks**; P18 native **398 checks** and CLI **106/106 checks**; P17 DSF instrument **84/84 fixtures**, plus four independent large streaming cases. Frozen guard and unqualified-certificate verifiers pass.
- **Prepared-host instrument:** one-second original-v1 and nominal-v2 input smoke tests correctly return `PASS_SHORT_SMOKE_ONLY`; both fail `--require-sustained`. These are *not* a substitute for hour-long unreset soaks.

These are independently executed software tests on the provided working set, not certified audio hardware/media tests. Cross-ISA results are for this host, not arbitrary deployment hosts.

## Still required before DSD1024 writing can be considered

1. **Prepared-host, uninterrupted ≥3,600-second soak** at DSD1024 for each original-v1 and nominal-v2 input program, with the new guard row, bit-window statistics and full host CPU/thermal/performance provenance. Evaluate with `p19_soak_assess.py --require-sustained`. Do not relabel shorter programs as a sustained pass.
2. Independent source material and reference reconstruction-quality evaluation over a representative program set, plus throughput, resource, and ISA tier tests on target hardware.
3. A new explicit release decision and separate file-writer/DoP interoperability work. All twelve P18 high-rate capability entries remain disabled here.

Do not promote the v2 candidate based only on the guards, the passing synthetic holdout or the single-tone diagnostic. The existing DSD512 work and its open qualification gates are unaffected.
