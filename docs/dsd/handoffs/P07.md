## Changes

- `src/rate.c`, `src/rate_internal.h`: add a private binary64 backend on
  the existing rate kernel; do not change the public `rate` handler. Use
  linear phase, 180 dB rejection, 95% **0-dB** bandwidth (`-B`, not `-b`),
  numeric zero extension instead of legacy LPC extrapolation, and an explicit
  caller-specified final sample limit.
- `src/dsd_public.c`, `src/sox_dsd.h`, `src/dsd.c`, `src/dsd.h`:
  add multichannel public decoder options, create/process/finish/destroy and
  reporting, exact rational frame counts with checked arithmetic, native
  clock-based output length (round exactly once), ceil(N/D) intermediate
  generation, independent per-channel private SRC instances, level-reference
  gain preserve=1 or SACD=2, and the allowed explicit PCM clocks through
  705,600 Hz.
- `src/dsdpcm.c`, `src/dsd_plan.c`, `src/effects.c`, `src/sox_i.h`,
  `src/sox_ng.c`, `src/formats.c`: integrate mono-per-flow graph effect,
  output-rate planning, strict/adapt bandwidth policy, pre-int32 clipping
  checks and diagnostics, private fatal status before interleaving, and
  visible CLI/finalization errors. Floating-point CLI output still crosses
  the int32 effects graph and can clip there; only the public double API
  retains overrange samples.
- `src/Makefile.am`, `test/Makefile.am`, `Makefile.am`: build and register
  production and test sources; make the default DSD phase P07; preserve the
  generic `make check` target. Add fail-closed preflight for missing required
  numerical modules.
- `test/dsd_test_p07*` sources and `tests/dsd/test_p07*.{c,py}`:
  exercise counts, tiny/empty streams, double-rounding counterexamples,
  multichannel ownership, chunk independence, overrange public doubles,
  strict/adapt, CLI fatal clipping and cleanup, public rate goldens, and
  independent SRC/composite/impulse comparisons. Exact C source filenames
  are in `test/Makefile.am`, and Python scripts in `Makefile.am`.
- `tests/dsd/certify_filters.py`, `generate_coeffs.py`, `test_decode.py`
  and new P07 reference scripts: missing Python numerical packages exit 2
  with a named **UNRUN**, rather than traceback or a false pass.

## Performance: development observations only; gate remains open

**P06 throughput** has an independent handoff. For the **P07-only native
path** comparison the control was *P06 plus isolated hotfix*, while the
candidate was *P06 plus isolated hotfix plus P07*. This is the correct second
phase baseline and is not a P05 comparison. The 40-pair six-channel DFF
small-buffer native repack test had median CPU ratio **0.99987** (-0.0128%
regression), bootstrap 95% ratio CI **[0.94423, 1.10716]**, and **32.02%**
measurement noise. The host violates the **2%** noise prerequisite, so the
verdict is **inconclusive**, not a 5% throughput pass.

Explicit P07 workloads **master64 -> 705,600 Hz** and **wide256 ->
705,600 Hz** were exercised in five repetitions at both 4,096- and
32-sample buffers. CPU and maximum resident memory are recorded in
`tests/dsd/results/P07/bench/explicit-decode.json`. Their PCM bytes match
across buffers. The host was not prepared or frequency-pinned; there was
no independent bandwidth-matched direct DSD decoder or matched staged
reference to compare, so **direct/staged control throughput gates are UNRUN**.
Do not use short development timings as a release throughput certification.
Full 36-workload phase benchmark passed as a development-only smoke matrix.

Test environment: Linux x86-64 container, Intel Xeon Platinum 8573C,
compiler `-O2 -g`; CPU isolation/fixed clocks unavailable; historical
`benchprep.sh` check reported CPU 8 nonexistent. `/dev/full` and the
external quality/holdout corpus were absent. No P07 forced-ISA or special
hardware qualification was claimed: P07 reuses the existing scalar rate
kernel, and those optional phase-specific capabilities were unavailable.
